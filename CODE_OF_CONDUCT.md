# Code of Conduct

This repository is a place to improve Team Chat together. Everyone who takes
part (in issues, pull requests, reviews and discussions) is expected to:

- be respectful and kind, including when you disagree;
- give and take feedback about the work, not the person;
- assume good intentions, and help newcomers;
- keep discussions on topic;
- follow the [Roblox Community Standards](https://about.roblox.com/community-standards)
  when talking about Roblox content.

Not allowed:

- harassment, insults, threats, discrimination or hateful language;
- sharing other people's personal information;
- spam, advertising, or posting the plugin's code or builds elsewhere
  (see [LICENSE.md](LICENSE.md));
- sexual or violent content.

## Enforcement

D3veloperHac may edit or remove comments, close issues and pull requests, and
block people from the repository who don't follow this code of conduct.

To report a problem, message @D3veloperHac on Roblox or use GitHub's report
feature on the comment or user.
